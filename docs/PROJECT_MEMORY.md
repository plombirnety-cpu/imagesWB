  7 schedule и 2 owner.

  39 полных выгрузок комментариев.
- Фактически доставлено 15 978 оплачиваемых записей: 265 постов и

- Финансовый API `/customer/balance` вернул 403 для текущего user-token; точную

## Актуально после исправления пустой выдачи (2026-07-28)

- Нельзя сопоставлять Google и TikTok только по одинаковому написанию. Канонический
  origin хранится в `google_origin_key` у seed и trend.
- Любой дочерний TikTok hashtag/comment seed наследует Google-origin поисковой темы.
  Повторно найденный URL должен прикрепить origin к уже существующему TikTok-тренду,
  а не остаться в старом несвязанном кластере.
- Opportunity использует Google-метрики origin и TikTok-метрики дочернего тренда.
  Строгое двойное доказательство сохранено: Google `>= 500`, два вирусных ролика разных
  авторов, суммарно `>= 100000` просмотров.
- Google-seed с объёмом ниже 500 не расходует лимит TikTok discovery. Явные
  utility-запросы (погода, телепрограмма, списки зачисленных, лунный календарь,
  магнитные бури, курсы валют, одиночные «банк/деньги») также исключены.
- Во время running-прохода пустой блок не является финальным результатом: UI пишет
  «промежуточный экран», показывает `N/6` и обещает автоматическое обновление.
- Каждый проход на 6 тем теперь резервирует 3 слота свежим Google-кандидатам и
  3 слота TikTok/Telegram-ротации: сильный новый Google-сигнал больше не может быть
  вытеснен накопленными TikTok-хештегами.
- Порог Google снижен до ранних 500+ только в связке со строгим TikTok-доказательством;
  один Google-сигнал по-прежнему никогда не создаёт идею для принта.
- Production-репродукция до фикса: 0 qualified при 49 TikTok-трендах; несколько
  дочерних кластеров уже имели достаточную TikTok-виральность, но не видели русскую
  Google-тему.
