# Память проекта Print Factory

## Актуально на 2026-07-26

- Production: `http://195.133.66.37:8040`, серверный каталог
  `/opt/print-panel`, контейнер `print-factory-panel`, Docker volume
  `panel_panel_out`.
- Панель закрыта паролем; секреты и `.env` не коммитить.
- Генерация использует Gemini, затем штатный GreenKey выдаёт прозрачный PNG.
- Style 37 больше не должен повторять одну машину по запросу марки:
  - ветка `automotive_subject` назначает каждой позиции отдельную конкретную
    модель до независимых вызовов Gemini;
  - встроены каталоги Mercedes-Benz/BMW/Porsche/Ferrari/Audi/Toyota/Nissan/Ford;
  - неизвестным маркам назначаются разные эпохи/категории;
  - точная модель с цифрами сохраняется и получает разные оформления;
  - восемь сеток и восемь смысловых углов ротируются по слотам;
  - текст только в universal neutral dual-contrast: neutral silver/greige,
    charcoal inner stroke + warm-ivory outer keyline; цвет кузова только в
    мелких акцентах.
- Для аниме-принтов ключевое требование — цельная фигурная композиция с
  эффектами и открытым контуром, не прямоугольная журнальная обложка и не
  стикер.
- Добавлен MVP TikTok-first радара:
  - SQLite `PANEL_RADAR_DB` живёт в том же постоянном volume;
  - TikTok — основной тип сигнала, Telegram/YouTube — подтверждения;
  - комментарии учитываются по уникальным авторам, copy-paste штрафуется;
  - первое обнаружение радаром не является датой рождения мема;
  - без даты и второго независимого сигнала только `UNVERIFIED`;
  - старый мем никогда не получает `NEW`/`RISING` из-за одних повторов;
  - старый новый всплеск называется `RESURGENCE`;
  - генерация возможна только после ручного `approve`.
- Важная пользовательская поправка: «Котость» — уже прошедший/зрелый мем,
  не пример раннего роста. Не делать вывод о новизне по популярности или
  сегодняшнему первому появлению в нашей базе.
- Ограничение MVP: публичные ссылки и комментарии вводятся/импортируются
  оператором; глобального скрейпинга TikTok пока нет.
- Новые тесты: 13/13 локально. Интерфейс визуально проверен без платной
  генерации.
- MVP выложен в production 2026-07-26 из commit `7ee87c3`.
  Linux-кандидат прошёл 378/378 тестов; контейнер после переключения healthy.
  База радара находится в `panel_panel_out`.
